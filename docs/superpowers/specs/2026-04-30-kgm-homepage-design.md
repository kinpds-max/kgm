## 페이지 섹션 상세

### 1. 헤더 / 네비게이션
- **모바일**: KGM 로고 + 딜러명 좌측 / 전화 아이콘 + 햄버거 메뉴 우측
- **데스크탑**: 로고 좌측 / 중앙 메뉴(홈·차량안내·프로모션·출고후기·상담문의) / 우측 "빠른 상담" 그린 버튼
- 스크롤 시 배경 반투명 처리 (backdrop-filter blur)
- 모바일 햄버거 클릭 시 풀스크린 오버레이 메뉴

### 2. 히어로 섹션
- 슬로건: "당신에게 맞는 KGM, 정확하게 안내해드립니다"
- 서브카피: "실매물 안내 · 맞춤 상담 · 신뢰 있는 차량 추천"
- CTA 버튼 2개: [차량 보기 →] [상담 신청 →]
- 우측 차량 이미지 (플레이스홀더 → 토레스 EVX 이미지로 교체 예정)
- 다크 오버레이 배경

### 3. 담당자 소개 카드
- 이종랑 부장 프로필 사진 (플레이스홀더)
- "이종랑 | KGM 일산중앙대리점"
- 신뢰 뱃지 (방패 아이콘)
- 소개 문구: "고객님의 조건에 맞는 최적의 차량을 제안해드립니다."

### 4. 차량 라인업

| 차종 | 분류 | 스펙 |
|------|------|------|
| 토레스 EVX | 전기 SUV | 433km / 204ps |
| 렉스턴 아레나 | 대형 SUV | 2,157cc / 202ps |
| 무쏘 EV | 전기 픽업 | 401km / 207ps |
| 티볼리 | 소형 SUV | 1,497cc / 163ps |

- 각 카드: 차량 이미지 + 차종명 + 배지 + 스펙 2개 + "상담문의 >" 버튼
- 모바일: 세로 카드 리스트 / 데스크탑: 가로 슬라이더

### 5. 내 차 찾기 필터
- 드롭다운 3개: 차종 (전체/SUV/픽업/세단) / 연료 (전체/전기/가솔린/디젤) / 가격대 (전체/3천만원 이하/3~5천만원/5천만원 이상)
- [내 차 찾기 →] 그린 버튼 → 선택한 필터 조건에 맞는 차량 카드만 표시 (JS 필터링)

### 6. 서비스 특징 (4개 아이콘)
1. 실차 중심 안내 — 실매물 기반의 정확한 정보 제공
2. 풍부한 상담 경험 — 다양한 출고 사례로 신뢰도 높은 상담
3. 맞춤 상담 — 고객님의 조건에 맞는 최적의 차량 제안
4. 빠른 문의 응대 — 전화·톡으로 신속하게 응대

### 7. 고객 후기 & 출고 사례
- 카드 3개 (가로 스크롤)
- 각 카드: 출고 사진 + 제목 + 내용 + 별점 (★★★★★ 5.0)
  1. 토레스 EVX 출고 후기 — "친절한 상담과 빠른 출고로 만족스럽습니다."
  2. 렉스턴 아레나 출고 후기 — "넓고 튼튼한 SUV를 찾고 있었는데 렉스턴 아레나가 최고네요."
  3. 무쏘 EV 출고 후기 — "전기 픽업이라 실용적이고 주행거리도 만족합니다!"
- 우상단 "더보기 >" 버튼 → 블로그 링크

### 8. 상담 신청 폼
- 섹션 제목: "상담 신청"
- 입력 필드: 이름 / 전화번호
- 버튼: [카카오톡으로 상담하기] (노란색 카카오 버튼, 링크는 추후 입력)
- 제출 시 동작: 버튼 클릭 → 카카오톡 오픈채팅 URL로 이동 (현재 placeholder `#`)

### 9. CTA 배너
- 텍스트: "지금 상담하고 가장 잘 맞는 차량을 만나보세요"
- 서브: "상담부터 출고까지, 이종랑이 책임지고 함께하겠습니다."
- 버튼: [☎ 이종랑 상담 010-5335-8102] → `tel:010-5335-8102`
- 우측 차량 이미지 (플레이스홀더)

### 10. 푸터
- 좌: KGM 일산중앙대리점 / 이종랑
- 중: 주소 / 대리점명
- 우: 문의 전화 / 영업시간 / SNS 아이콘 (전화·카카오·네이버블로그·유튜브)

### 11. 모바일 하단 고정 바

- 네비게이션 메뉴 클릭 → 해당 섹션으로 부드럽게 스크롤 (`scroll-behavior: smooth`)
